# Link Mobility

Source: https://docs.omnium.no/docs/plugins/Other/LinkMobility

> Guide for setting up Link Mobility in Omnium.

## Link Mobility plugin

### Introduction

With the Link Mobility integration, you can configure SMS notifications in Omnium based on various events and order statuses.

### Getting started

To get started, you must first set up an agreement with Link Mobility.

1.  **Contact Link Mobility** to obtain a license and establish the agreement.
2.  Once the agreement is in place, **Link Mobility will reach out to Omnium** to configure the integration in your system.

### Set up

SMS providers are configured under:

**Configuration → Advanced → Notifications → SMS Client**

See [SMS Client Settings](../../configuration/sms-client-settings.md) for a full guide on how to add and configure SMS providers, including availability filters for stores, markets, and market groups.

When adding a Link Mobility entry, select `vianett` as the type and fill in the credentials provided by Link Mobility.

Once the integration is ready, you can proceed to configure your notifications.
